# Realtime Messenger (UA)

Реальна система комунікації на базі `Node.js` (без зовнішніх залежностей).

## Можливості
- Реєстрація користувача по імені та номеру телефону.
- Онлайн-список активних користувачів.
- Загальний чат у реальному часі (між різними вкладками/браузерами).
- Срочні повідомлення:
  - **загальні** (всім),
  - **персональні** (конкретному номеру телефону).
- Full-screen оверлей при отриманні срочного повідомлення.
- Готові приклади срочних текстів:
  - `У вас вода кипить`
  - `У вас їжа горить`

## Запуск
```bash
npm start
```

Після запуску відкрийте: `http://localhost:4173`

## Як перевірити персональні срочні
1. Відкрийте сайт у двох вкладках.
2. Увійдіть під двома різними телефонами.
3. У вкладці **Срочні** оберіть тип **Персональне**.
4. Впишіть телефон отримувача.
5. Надішліть повідомлення — його побачить тільки адресат і відправник.
