# Realtime Messenger (UA)

Оновлений чат із:

- вхід як **гість**;
- паролі для акаунтів (для реєстрації);
- реєстрація через **телефон + SMS код (демо)**;
- реєстрація через **email + код (демо)**;
- перевірка унікальності: **не можна повторно зареєструвати той самий телефон/email**;
- загальний чат і срочні повідомлення (global/personal);
- техпідтримка: користувач пише, адмін відповідає;
- адмін-панель: блокування/розблокування і вигнання користувачів.

## Запуск

```bash
npm start
```

Відкрити: `http://localhost:4173`
