# Lite Messenger (UA)

Простий фронтенд-застосунок чату з:

- реєстрацією за ім'ям і номером телефону;
- базовим обміном повідомленнями в стилі месенджера;
- кнопкою "дзвінок" (імітація);
- вкладкою "Срочні", де можна відправити термінове повідомлення, яке відкривається поверх усього екрану.

## Запуск

Відкрийте `index.html` у браузері.

Дані зберігаються в `localStorage`.
